Product Details

Radxa NX4 is a high-performance AI compute module based on the Rockchip RK3576(J), using a 260-pin SO-DIMM form factor (69.6 mm × 45 mm). It integrates a quad-core Cortex-A72 + quad-core Cortex-A53 CPU, ARM Mali G52 MC3 GPU, and a 6 TOPS@INT8 NPU with support for mainstream deep learning frameworks. With its rich interfaces, NX4 is ideal for edge computing, machine vision, and intelligent terminal applications.

Hardware Spec

  • SoC

    Rockchip RK3576(J)

  • CPU

    Quad Cortex-A72 + Quad Cortex-A53

  • GPU

    ARM Mali G52 MC3

    - Support OpenGL ES 1.1, 2.0 and 3.2, OpenCL 2.1, Vulkan 1.2

  • NPU

    6 TOPS@INT8

    - Support INT4 / INT8 / INT16 / FP16 / BF16 / TF32 computation precision

    - Support deep learning frameworks: TensorFlow, Caffe, Tflite, Pytorch, Onnx NN, Android NN, etc

  • RAM

    LPDDR5

    - Capacity: up to 16GB

    - Memory bus width: 32-bit (dual-channel, 16-bit per channel)

    - Data rate: up to 5500 MT/s

  • Storage

    Optional eMMC 5.1 or UFS 2.0

    - eMMC 5.1, up to 256GB

    - UFS 2.0, up to 1TB

    Optional onboard SPI Flash

    1x SDMMC

  • Multimedia

    Video Encoder

    - H.265 multivideo encoder up to 4K@60fps

    Video Decoder

    - AV1 / AVS2 / VP9 / H.265 multivideo decoder up to 8K@30fps or 4K@120fps

    - H.264 multivideo decoder up to 4K@60fps

  • Networking

    1x Gigabit Ethernet

    Onboard WiFI 6 & BT5.4

    - Onboard antenna connector

  • Display

    1x HDMI 2.1

    - up to 4K@120Hz

  • Camera

    2x MIPI CSI (4-lane)

  • USB

    USB 3.2

    USB 2.0

  • PCIe

    1 x PCIe2.0 1‑lane

  • Other IO

    Support UART, I2C, I2S, CAN, PWM, GPIOs, etc

  • Software

    Debian

    Yocto

    Buildroot

    Android 14

  • Power Input

    5V DC

  • Operating Conditions

    0 - 60°C (Commercial Grade)

    -40°C to 85°C (Industrial Grade)

  • Dimension

    69.6 mm x 45 mm

  • Connector

    260-pin SO-DIMM connector
