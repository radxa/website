Product Details

The Radxa NX5 is a System on Module (SoM) based on a the Rockchip RK3588S System on Chip (SoC). The Radxa NX5 integrates the Central Process Unit(CPU), Graphics Processing Unit (GPU), Neural Processing Unit (NPU), Power Management Unit (PMU), LPDDR4X DRAM Memory, and Onboard eMMC Storage in a small form factor of just 70mm x 45mm. Radxa NX5 offers out of box high performance solution for multiple purpose applications, accelerates customer’s product development.

Hardware Spec

  • SoC

    Rockchip RK3588S

  • CPU

    Quad Cortex®‑A76 @ 2.2~2.4GHz and a quad Cortex®‑A55 @ 1.8GHz based on Arm®DynamIQ™ configuration

  • GPU

    Arm Mali™ G610MP4 GPU

    - OpenGL® ES1.1, ES2.0, and ES3.2

    - OpenCL® 1.1, 1.2 and 2.2

    - Vulkan® 1.1 and 1.2

    - Embedded high performance 2D image acceleration module

  • NPU

    NPU supporting INT4 / INT8 / INT16 / FP16 / BF16 and TF32 acceleration

    Computing power is up to 6TOPs

  • RAM

    64bit LPDDR4x

    - 1GB

    - 4GB

    - 8GB

    - 16GB

  • Storage

    Optional 4GB / 8GB / 16GB / 32GB, up to 512GB Onboard eMMC Compatible with eMMC 5.1

    Supports SDMMC interface for data storage and OS booting using SD cards

  • Multimedia

    VP9 / H.265 / AVS2 decode 8K@60fps

    H.264 / H.265 encode 8K@30fps

    etc

  • Ethernet

    1 x Onboard Gigabit Ethernet PHY

  • Display

    1x HDMI TX up to 8K@60hz

    1x eDP TX up to 4K@60Hz

    1x DP TX (and USB3.0 Combo) up to 8K@30Hz

    1x 2-lane MIPI D/C PHY TX

  • Camera

    2x 2-lane or 1 x 4-lane MIPI CSI for Camera

    1x 2-lane MIPI D/C-PHY RX

    1x 4-lane MIPI D/C-PHY RX

  • Audio

    Up to 2x I2S

    Up to 2x PDM

    Up to 2x SPDIF TX

  • USB

    2 × USB 2.0 Host Port (HighSpeed)

    1 x USB 3.0 Host Port (SuperSpeed)

    1 x USB 3.0 OTG Port

  • PCIe

    2 x PCIe2.0 1‑lane

    - one shared with USB3 and SATA

    - one shared with SATA

  • SATA

    2 x SATA ports

    - one shared with USB3 and PCIe2.0

    - one shared with PCIe2.0

  • Connectivity

    Up to 10x UART

    Up to 5x SPI

    Up to 3x CAN

    Up to 7x I2C

    Up to 15x PWM

  • Software

    Radxa OS

    Debian

    Android

    Various third-party images

    For more information click on Downloads

  • Power Input

    5V DC, Max 5.2V

  • Operating Conditions

    Recommended environmental temperature: 0 ~ 50°C

    Radxa NX5 has a temperature limit of 80°C, beyond which it throttles clock speeds for reliability

    For continuous high-performance use, external cooling methods like heat sinks or fans can maintain maximum clock speed below the 80°C limit

  • Dimension

    70mm x 45mm

  • Connector

    260-Pin SODIMM Golden Finger Edge Connector

  • Compliance Certification

    FCC / CE
