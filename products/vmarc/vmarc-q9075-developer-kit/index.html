Powered by the Qualcomm Dragonwing IQ-9075 Processor

Designed for demanding robotics and edge intelligence, the IQ-9075 combines high-performance application compute, on-device AI acceleration, advanced graphics, and real-time control on a unified platform.

High-Performance Application Compute

8-core Kryo Gen 6

  • Dual quad-core clusters
  • Up to 2.36GHz
  • Built for compute-intensive applications

On-Device AI Engine

Dual Qualcomm Hexagon Tensor Processors

  • Up to 100 Dense TOPS / 200 Sparse TOPS
  • HVX vector and HMX matrix acceleration
  • Built for vision, multimodal, and generative AI workloads

Real-Time Control Subsystem

Quad-core Arm Cortex-R52

  • Up to 1.85GHz
  • Configurable in lock-step or split mode
  • Supports independent boot via OSPI

Advanced Graphics & GPU Compute

Qualcomm Adreno 663

  • Up to 840MHz
  • Supports Safe GPGPU Compute
  • Supports Adreno NN Direct

OpenGL ES 3.2
