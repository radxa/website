Product Details

The Radxa VMARC-Q9075 SoM, powered by the Qualcomm Dragonwing IQ-9075, integrates a 200 Sparse TOPS AI Performance, 8-core Kryo Gen 6 CPU, Adreno 663 GPU, 4-core Cortex-R52 MCU, 36GB LPDDR5, and 128GB UFS 3.1 storage into the 82mm × 80mm SMARC standard form factor—delivering powerful AI performance and versatile I/O expansion in a compact design.

Hardware Spec

  • Form Factor

    SMARC (82mm x 80mm)

  • SoC

    Qualcomm Dragonwing IQ-9075

  • CPU

    8-core Kryo Gen 6, up to 2.36GHz

  • GPU

    Qualcomm Adreno 663

    - Delivers 1.2 TFLOPS FP32 with secure GPU compute

    - Supports Vulkan 1.2, OpenGL ES 3.2, OpenCL 2.0 FP

    - Supports Adreno NN Direct

  • NPU

    200 Sparse TOPS@INT8

    - Features the Hexagon Tensor Processor (HTP) with quad HVX and dual HMX

    - Supports deep-learning frameworks: TensorFlow, PyTorch, ONNX, Paddle, Caffe, DarkNet, etc.

  • Display

    1x 4-lane MIPI DSI

    1x Embedded DisplayPort (eDP)

    1x HDMI TX signals (DP1.4 to HDMI)

    1x DisplayPort (DP)1.4 TX signals

    Up to 4K60

  • MCU

    4-core Cortex-R52, up to 1.85GHz

  • RAM

    LPDDR5

    - Capacity: 36GB

    - Memory bus width: 96-bit

    - Data rate: up to 6400 MT/s

  • Codec

    Adreno VPU 765

    Video Decoder:

    - Supports AV1, HEVC, H.264, H.265, VP9, and MPEG2 formats

    - Capabilities: 1x 8Kp60 / 2x 8Kp30 / 4x 4Kp60 / 8x 4Kp30 / 16x 1080p60 / 32x 1080p30

    Video Encoder:

    - Supports H.264, H.265, HEIF, and HEIC formats

    - Capabilities: 2x 4Kp60 / 4x 4Kp30 / 8x 1080p60 / 16x 1080p30

  • Storage

    1x Onboard 32MB SPI Flash

    1x Onboard 128GB UFS 3.1 (Gear4 x2)

  • Camera

    1x MIPI CSI (4-lane)

    1x MIPI CSI (2-lane)

  • Ethernet

    2× 2.5GbE PHY

  • USB

    2x USB 3.2 Gen 2 (10Gbps)

    4x USB 2.0

  • PCIe

    2x PCIe Gen4 x2

  • Connectivity

    2x CAN

    2x I2S

    4x UART

    2x SPI

    GPIO

  • Connector

    314-pin MXM 3.0 Connector

  • Operating Conditions

    Operating Temperature: 0°C to +60°C

  • Dimension

    82 mm x 80 mm
