Product Details

The Radxa CM3J, an industrial compute module brimming with an array of advanced features, is meticulously crafted based on the Rockchip RK3568J SoC. This extraordinary module showcases its prowess by seamlessly integrating the CPU, GPU, NPU, PMU, LPDDR4 memory, Wi-Fi, and eMMC storage within a remarkably compact form factor, measuring a mere 55mm x 40mm.

Hardware Spec

  • SoC

    Rockchip RK3568J

  • CPU

    Quad‑core Arm® Cortex™‑A55 (Armv8) 64‑bit @ 2.0GHz

  • GPU

    Arm® Mali™ G52 GPU

    - OpenGL® ES 1.1 / 2.0 / 3.2

    - OpenCL™ 2.0

    - Vulkan® 1.1

  • NPU

    NPU supporting INT8 / INT16 / FP16 / BFP16, computing power is up to 1TOPs@INT8

  • Codec

    H.265 / H.264 and VP9 video decoder up to 4K@60fps

    H.264 / H.265 video encoder up to 1080P@100fps

  • RAM

    LPDDR4/LPDDR4x 2/4/8GB

  • Storage

    onboard eMMC

    SPI Flash for bootloader

    Supports SDMMC interface for data storage and OS booting using SD cards

  • Wireless

    IEEE 802.11 b/g/n/ac Wireless LAN (Wi-Fi 5) with external antenna connector

    BT 5.0 with BLE

  • Ethernet

    1x Onboard Gigabit Ethernet PHY

  • Video Output

    1x HDMI TX up to 4096X2160@60Hz

    1x 2‑lane MIPI DSI for MIPI LCD

    1x 4‑lane MIPI DSI for MIPI LCD

    1x LVDS 4-lane(muxed with MIPI DSI0)

  • Video Input

    1x 4‑lane MIPI CSI RX or 2x 2‑lane MIPI CSI RX

  • USB

    1x USB 2.0 OTG / HOST Interface

  • PCIe

    1x PCIe 2.0 1‑lane Interface

  • Connectivity

    UART

    SPI

    I2C

    CAN

    I2S

    GPIO

  • Connector

    2 x 100 pins B2B connector

  • Operating Conditions

    Recommended environmental temperature: -40°C ～ 85°C

  • Software

    Debian

  • Dimension

    55 mm × 40 mm
