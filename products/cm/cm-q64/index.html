Product Details

Radxa CM-Q64 is a compact compute module powered by the Qualcomm Dragonwing QCS6490 platform. It combines an 8-core Kryo 670 CPU, 12 TOPS Hexagon NPU, up to 16GB LPDDR5, 4K video processing, triple ISP, 2.5GbE, Wi-Fi 6, and USB 3.2 in a 55mm x 40mm form factor, making it ideal for edge AI, robotics, IoT, and embedded vision applications.

Hardware Spec

  • SoC

    Qualcomm Dragonwing QCS6490

  • CPU

    8-core Kryo 670 CPU

    - 1x Kryo Gold Prime @ 2.7 GHz

    - 3x Kryo Gold @ 2.4 GHz

    - 4x Kryo Silver @ 1.9 GHz

    - 6nm process

  • AI Performance

    Qualcomm Hexagon 770

    - 12 TOPS dense compute

    - Dual HVX + Hexagon CP 2.0 + Hexagon Tensor Accelerator

  • GPU

    Qualcomm Adreno 643 GPU @ 812 MHz

    - OpenGL ES 3.2

    - OpenCL 2.0

    - Vulkan 1.x

    - DirectX 12

  • Memory

    LPDDR5

    - Capacity: Up to 16GB

    - Bus width: 32-bit (2 channels × 16-bit)

  • Codec

    Qualcomm Adreno 633 VPU

    - Decoding: 1×4K60 / 2×4K30 / 4×1080p60 (H.264 / H.265 / VP9)

    - Encoding: 1×4K30 / 4×1080p30 (H.264 / H.265)

    - Concurrent: 1080p60 decode + 1080p60 encode / 4K30 decode + 1080p30 encode

    - HDR: HDR10 / HDR10+

  • Display

    Qualcomm Adreno 1075 DPU

    - 1× USB-C with DP 1.4 Alt Mode (up to 4K60)

    - 1× HDMI 2.0 (up to 4K60)

    - 1× MIPI DSI (4-lane)

    - Up to dual independent displays

  • Camera

    Qualcomm Spectra 570L ISP (Triple ISP)

    - 2× MIPI CSI (2-lane)

    - 1× MIPI CSI (4-lane)

    - Up to 4 camera inputs depending on lane allocation and software support

  • Storage

    microSD expansion (SDIO 3.0)

    Onboard eMMC 5.1 or UFS 3.1 (Optional)

    NVMe expansion (PCIe Gen3 ×2)

  • Networking

    Onboard Ethernet controller (1GbE or 2.5GbE optional)

    Onboard FCU760K wireless module (Wi-Fi 6 + BT 5.4, optional)

  • USB

    USB 3.2 Gen 1

    USB 2.0

  • Audio

    Qualcomm Hexagon DSP (1980 MPPS) + WCD9385 audio codec

    - Supports headphone output and microphone input

  • Connectivity

    Supports UART, I2C, SPI, PWM, GPIO

  • Connector

    3× 100-pin B2B Connector

  • Operating System

    Qualcomm Linux

    Windows

    Ubuntu

  • Dimension

    55 mm × 40 mm
