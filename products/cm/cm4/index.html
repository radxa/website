Product Details

Radxa CM4 is a high-performance system-on-module designed to bring the capabilities of the RK3576 processor to space-constrained and custom embedded applications. Built around a 55 mm × 40 mm compact form factor, CM4 is ideal for industrial control, edge computing, computer vision, and multimedia applications.

Hardware Spec

  • SoC

    Rockchip RK3576(J)

  • CPU

    Quad-Core Cortex-A72 + Quad-Core Cortex-A53, Up to 2.2GHz

  • GPU

    ARM Mali G52 MC3

    - OpenGL® ES 1.1 / 2.0 / 3.2

    - Vulkan® 1.2, OpenCL™ 2.1

  • NPU

    6 TOPS@INT8

    - Supports INT4/INT8/INT16/FP16/TF32

    - Supports mainstream AI frameworks: TensorFlow, ONNX, PyTorch, Caffe

  • Multimedia

    - AV1 / AVS2 / VP9 / H.265 multivideo decoder up to 8K@30fps or 4K@120fps

    - H.264 multivideo decoder up to 4K@60fps

    - H.265 multivideo encoder up to 4K@60fps

  • RAM

    LPDDR4X RAM up to 16GB

  • Storage

    Onboard eMMC Up to 256GB

    Optional onboard SPI Flash

    Support UFS 2.0 Module for data storage and OS booting

    Supports SDMMC interface for data storage and OS booting

  • Ethernet

    1x Onboard Gigabit Ethernet PHY

  • Wireless

    Onboard WiFi 6 / BT 5.4 with external antenna

  • Video Input

    1x 4‑lane MIPI CSI or 2x 2‑lane MIPI CSI

  • Video Output

    1x HDMI TX up to 4K@120Hz

    1x 4‑lane eDP Interface up to 4K@60fps

    1x DP Interface up to 4K@120fps

    1x 4‑lane MIPI DSI for MIPI LCD

    Able to provide 2x display output

  • USB

    1x USB 3.2 Gen1x1 OTG / HOST

    1x USB 3.2 Gen2x1

  • PCIe

    2x PCIe Gen2 1‑lane

  • SATA

    2x SATA 3.1

  • Connectivity

    - GPIO

    - I2C

    - SPI

    - UART

    - PWM

    - ADC

    - SDIO

    - I2S

    - PDM with microphone array support

  • Connector

    3 x 100 pins 0.4mm pitch B2B connector

  • Operating Conditions

    0°C to 60°C(Commercial Grade)

    ‑40°C to 85°C(Industrial Grade)

  • Software

    Support Debian / Linux / Buildroot / Android

  • Dimension

    55 mm × 40 mm
