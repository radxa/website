产品概述

瑞莎 NX5 是基于瑞芯微 RK3588S 片上系统 (SoC) 的系统模块 (SoM)。瑞莎 NX5 集成了中央处理器 (CPU)、图形处理器 (GPU)、神经处理单元 (NPU)、电源管理单元 (PMU)、LPDDR4X DRAM 存储器和板载 eMMC 存储器，外形小巧，仅为 70mm x 45mm。瑞莎 NX5 为多种用途的应用提供了开箱即用的高性能解决方案，加速了客户的产品开发。

硬件接口

产品参数

  • 主控

    瑞芯微 RK3588S

  • 中央处理器

    基于 Arm® DynamIQ™ 配置的四核 Cortex®‑A76 @ 2.2~2.4GHz 和四核 Cortex®‑A55 @ 1.8GHz

  • 图形处理器

    Arm Mali™ G610MP4 GPU

    - OpenGL® ES1.1, ES2.0, and ES3.2

    - OpenCL® 1.1, 1.2 and 2.2

    - Vulkan® 1.1 and 1.2

    - 内嵌高性能 2D 图像加速模块

  • 神经网络处理器

    支持 INT4 / INT8 / INT16 / FP16 / BF16 和 TF32 加速

    算力最高可达 6TOPs

  • 内存

    64bit LPDDR4x

    - 1GB

    - 4GB

    - 8GB

    - 16GB

  • 存储

    可选 4GB / 8GB / 16GB / 32GB，板载 eMMC 最高可选 512GB，兼容 eMMC 5.1

    支持 SDMMC 接口，可使用 SD 卡进行数据存储与系统启动

  • 视频编解码

    VP9 / H.265 / AVS2 解码最高可达 8K@60fps

    H.264 / H.265 编码最高可达 8K@30fps

  • 以太网

    1 x 板载千兆以太网 PHY

  • 显示

    1x HDMI TX，最高可达 8K@60hz

    1x eDP TX，最高可达 4K@60Hz

    1x DP TX（与 USB3.0 复用），最高可达 8K@30Hz

    1x 2 通道 MIPI D/C PHY TX

  • 摄像头

    2x 2 通道或 1 x 4 通道 MIPI CSI 摄像头接口

    1x 2 通道 MIPI D/C-PHY RX

    1x 4 通道 MIPI D/C-PHY RX

  • 音频

    最多 2x I2S

    最多 2x PDM

    最多 2x SPDIF TX

  • USB

    2 × USB 2.0 Host

    1 x USB 3.0 Host

    1 x USB 3.0 OTG

  • PCIe

    2 x PCIe2.0 单通道

    - 一个与 USB3 和 SATA 共享

    - 一个与 SATA 共享

  • SATA

    2 x SATA 接口

    - 一个与 USB3 和 PCIe2.0 共享

    - 一个与 PCIe2.0 共享

  • 其它接口

    最多 10x UART

    最多 5x SPI

    最多 3x CAN

    最多 7x I2C

    最多 15x PWM

  • 操作系统

    Radxa OS

    Debian

    Android

    多种第三方镜像

  • 电源

    5V DC，最高 5.2V

  • 工作环境

    推荐环境温度：0 ~ 50°C

    瑞莎 NX5 有温度限制为 80°C，超过此温度范围时会降低时钟频率以保证可靠性

    如需持续高性能运行，可通过散热片或风扇等外部散热方式，将温度维持在 80°C 限制以下，从而保持最高时钟频率

  • 机械尺寸

    70 毫米 × 45 毫米

  • 连接接口

    260-Pin SODIMM 连接器

  • 合规认证

    FCC / CE
