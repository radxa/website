产品概述

瑞莎 CM3I 是一款采用瑞芯微 RK3568(J) SoC 的高性能计算模块，将 CPU、GPU、NPU、PMU、LPDDR4 内存和 eMMC 存储器巧妙地集成在 70mm x 40mm 的紧凑外形中。该模块不仅拥有卓越的计算能力，而且在图形渲染和人工智能计算方面也具有非凡的功能。

硬件接口

产品参数

  • 主控

    瑞芯微 RK3568(J)

  • 中央处理器

    四核 Cortex-A55，最高主频可达 2.0GHz

  • 图形处理器

    Arm® Mali™ G52 GPU

    - OpenGL® ES 1.1 / 2.0 / 3.2

    - OpenCL™ 2.0

    - Vulkan® 1.1

  • 神经网络处理器

    1 TOPS@INT8，支持 INT8、INT16、FP16、BFP16 混合运算

    支持深度学习框架：TensorFlow、TF-lite、Pytorch、Caffe、ONNX、MXNet、Keras、Darknet

  • 内存

    LPDDR4 内存

  • 存储

    可选板载 eMMC

    支持 SDMMC 接口，可使用 SD 卡进行数据存储与系统启动

  • 视频编解码

    H.265 / H.264 和 VP9 视频解码，最高可达 4K@60fps

    H.264 / H.265 视频编码，最高可达 1080P@100fps

  • 无线

    可选无线局域网，2.4GHz 和 5.0GHz，IEEE 802.11b/g/n/ac

    BT 5.0，支持 BLE

    1x 外置天线接口

  • 以太网

    1x 板载千兆以太网 PHY

    1x 千兆以太网 MAC

  • USB

    2 × USB 2.0 Host

    1 x USB 3.0 Host

    1 x USB 3.0 OTG

  • PCIe

    1 × PCIe 1 通道 Host，Gen 2（5Gbps）

    1 x PCIe 2 通道（1x2、1x1+1x1）Host，Gen 3（16Gbps）

  • SATA

    3 x SATA 端口

    - 其中一个与 USB 3 HOST 复用

    - 其中一个与 PCIe 复用

    - 其中一个与 USB 3 OTG 复用

  • 显示

    1x HDMI，最高 4Kx2K@60fps

    1x eDP（4 通道），每通道 2.7Gps

    2x MIPI DSI（4 通道），每通道 1.6Gbps

    1x LVDS（4 通道）（与 MIPI DSI0 复用）

  • 视频输入

    1x 4 通道 MIPI CSI 或 2x 2 通道 MIPI CSI

    1x 4 通道 MIPI_D/C PHY

  • 其它接口

    最多 8x UART

    最多 4x SPI

    最多 2x CAN

    最多 4x I2C

  • 音频

    I2S

    PDM，支持麦克风阵列

  • 连接接口

    4x 100pin 0.4mm 间距 B2B 接口

  • 机械尺寸

    70 毫米 x 40 毫米

  • 工作环境

    J0 型号（RK3568）：0 ~ 50°C

    J1 型号（RK3568J）：‑40 ~ 85°C

  • 合规认证

    FCC / CE
