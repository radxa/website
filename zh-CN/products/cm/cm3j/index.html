产品概述

瑞莎 CM3J 是一款基于瑞芯微 RK3568J SoC 的工业级计算模块，将 CPU、GPU、NPU、PMU、LPDDR4 内存、WiFi 和 eMMC 存储集成在 55 毫米 × 40 毫米的紧凑尺寸中。

硬件接口

产品参数

  • 主控

    瑞芯微 RK3568J

  • 中央处理器

    四核 Cortex™‑A55，最高主频可达 2.0GHz

  • 图形处理器

    Arm® Mali™ G52 GPU

    - OpenGL® ES 1.1 / 2.0 / 3.2

    - OpenCL™ 2.0

    - Vulkan® 1.1

  • 神经网络处理器

    1 TOPS@INT8

    支持 INT8 / INT16 / FP16 / BFP16 计算精度

  • 视频编解码

    H.265 / H.264 和 VP9 视频解码最高可达 4K@60fps

    H.264 / H.265 视频编码最高可达 1080P@100fps

  • 内存

    LPDDR4/LPDDR4x 内存，可选容量 2 / 4 / 8GB

  • 存储

    板载 eMMC

    SPI Flash，用于 Bootloader

    支持 SDMMC 接口，可使用 SD 卡进行数据存储与系统启动

  • 无线

    IEEE 802.11 b/g/n/ac 无线局域网（WiFi 5），外置天线接口

    蓝牙 5.0，支持 BLE

  • 以太网

    1x 板载千兆以太网 PHY

  • 显示

    1x HDMI TX，最高可达 4096X2160@60Hz

    1x 2 通道 MIPI 显示屏接口

    1x 4 通道 MIPI 显示屏接口

    1x 4 通道 LVDS，与 MIPI DSI0 复用

  • 视频输入

    1x 4 通道 MIPI CSI RX 或 2x 2 通道 MIPI CSI RX

  • USB

    1x USB 2.0 OTG / HOST 接口

  • PCIe

    1x PCIe 2.0 单通道接口

  • 其它接口

    UART

    SPI

    I2C

    CAN

    I2S

    GPIO

  • 连接接口

    2x 100pin B2B 接口

  • 工作环境

    推荐环境温度：-40°C ～ 85°C

  • 操作系统

    Debian

  • 机械尺寸

    55 毫米 × 40 毫米
