产品概述

瑞莎 rCore-Q8280 搭载高通骁龙 8cx Gen 3，集成八核 Kryo CPU、Adreno GPU 与 29+ TOPS AI 算力。支持最高 32GB LPDDR4X、UFS、NVMe、多路 4K 显示及高速 USB，适合边缘 AI、智能终端、多媒体处理与工业设备集成。

硬件接口

产品参数

  • 主控

    Snapdragon® 8cx Gen 3 (SC8280XP)

  • 中央处理器

    Qualcomm® Kryo™ CPU

    - 8 核 CPU, 4x Kryo Prime @3.0GHz + 4x Kryo Gold @2.4GHz

    - 64 位 CPU 架构

  • 图形处理器

    Qualcomm® Adreno™ 690 GPU

    - 2.7 TFLOPS 算力

    - 支持 DirectX 12 和 DirectML

  • 神经网络处理器

    Qualcomm® Hexagon™

    - 高达 15 TOPS

  • AI 性能

    Qualcomm® AI Engine

    - 高达 29+ TOPS

  • 制程

    5nm 制程工艺

  • 编解码

    Adreno VPU（第五代 UHD 视频处理单元）

    - 视频解码：H.265 / H.265 / H.264 / VP9, 最高支持 4K@120fps

    - 视频编码：H.265 / H.265 / H.264, 最高支持 4K@60fps

  • PCIe

    PCIe Gen3

    - 最多 9 条 PCIe Gen 3 通道；

    - 可配置为 2+2+2+2+1 或 4+4+1

  • 内存

    LPDDR4X

    - 容量: 最大可选 32GB

    - 内存总线宽度: 128 位 (8 通道, 每通道 16 位)

  • 存储

    microSD，通过 SD 3.0

    UFS，通过 UFS 3.1 Gear 4

    NVMe，通过 PCIe

  • 显示

    高通 Adreno 1199 DPU

    - 2x 4 通道 DP / eDP

    - 1x 4 通道 MIPI DSI

    - 2x DisplayPort v1.4 (通过 USB-C 输出), 最高 4K@120Hz

  • 摄像头

    高通 Spectra ISP

    - 1x 4 通道 MIPI CSI

  • USB

    2x USB 3.1 Gen2 10 Gbps

    2x USB 3.1, Type-C with DisplayPort v1.4

    1x USB 2.0

  • 音频

    Qualcomm® 低功耗音频子系统（LPASS）

    - SoundWire 音频接口，用于连接音频 Codec 和扬声器功放

  • 供电

  • 其他

    228 GPIOs

    24 组 QUP

    - 可复用 I2C / I3C / SPI / UART 等串行接口

  • 操作系统

    Radxa OS

    Windows

    Ubuntu

    Debian

    fnOS

    ···

  • 封装

    1580-Ball BGA

  • 尺寸

    50 mm x 80 mm

    8 核 Kryo CPU

    先进媒体与显示引擎

    流畅的 4K 视频播放与灵活显示连接，支持通过 USB-C DisplayPort 或 DP/eDP 实现最高 4K@120 输出。

    视频处理

    • Qualcomm Adreno VPU
    • 视频解码：H.265 / H.264 / VP9，最高 4K@120
    • 视频编码：H.265 / H.264，最高 4K@60

    显示输出

    • Qualcomm Adreno 1199 DPU
    • 1x 4 通道 MIPI DSI
    • 2x 4 通道 DP / eDP
    • 2x USB-C，支持 DP1.4 Alt Mode

    高速内存与灵活存储

    高速 LPDDR4X 内存与灵活的存储选项，让系统始终保持流畅、响应迅速，并轻松应对更多任务。

    1. 最高 32GB 128-bit LPDDR4X

    2. 通过 SD 3.0 的 microSD

    3. 通过 UFS 3.1 Gear 4 的 UFS

    4. 通过 PCIe 的 NVMe

    5. 32MB SPI NOR Flash

    丰富连接，拓展更多可能

    配备丰富的高速接口与灵活的外设支持，为显示、存储、摄像、音频及工业 I/O 应用提供强大扩展能力。

    连接接口

    • 1x PCIe Gen3 x9
    • 2x USB 3.2 Gen2 10 Gbps
    • 2x DisplayPort 1.4（通过 USB-C 接口输出）
    • 1x USB 2.0
    • I2C / I3C / SPI / UART

    显示接口

    • 2x 4 通道 DP / eDP
    • 1x 4 通道 MIPI DSI
    • 2x USB-C (10Gbps) 支持 DP1.4 Alt 模式

    音频接口

    • SoundWire

    摄像头接口

    • 1x 4 通道 MIPI CSI

    紧凑可靠的封装设计

    紧凑的 50 mm x 80 mm 外形尺寸，配合 1580 球 BGA 封装以及丰富的 GPIO / QUP 控制接口，便于集成到定制化产品中。

    1580 球 BGA 封装

    宽温支持

    0°C 至 60°C
