通过 HDMI 和 USB 将瑞莎灵控接入目标设备，即可在浏览器中查看并远程控制该设备。

  1. 无需鼠标

  2. 无需键盘

  3. 无需显示器

远程设备操控，一应俱全

瑞莎灵控将连接、控制、恢复与自动化功能集成于紧凑的硬件之中。

  1. 连接与发现

    选择适合设备的连接方式，并通过浏览器控制中心发现灵控。

    • 专属 Web 应用
    • Wi-Fi 控制
    • USB 控制
    • LAN 控制

  2. 控制与恢复

    清晰查看目标设备，在操作系统启动前的环境中工作，并可远程恢复系统，无需亲临现场。

    • 分辨率
    • 屏幕录制
    • 虚拟磁盘支持
    • 拇指大小

  3. 自动化与安全防护

    可在任何操作系统上使用灵控，确保访问安全，并将重复性任务交由智能体处理。

    • Agent 就绪
    • 免驱动
    • 2FA
    • 多系统支持

瑞莎灵控，为何与众不同

让人和 AI 智能体可以从任何地方控制真实设备。

面向 Agent 的硬件
无需安装任何软件
浏览器即控制台
预启动与 BIOS 访问

高清视频传输

最高支持 2K@30Hz 视频输入及多种串流方式，带来清晰流畅的浏览器端画面。

  1. 最高支持 2K@30Hz 视频输入

  2. 支持 H.264 和 MJPEG 编码

  3. H.264 通过 WebRTC 传输；MJPEG 通过 WebSocket 传输

灵活连接，适配多种工作场景

适用于各种部署环境，让设备适应你的连接方式，而不是让你迁就设备

USB-C 转 RJ45 以太网

USB-C 直连

内建安全与隐私保护

从设备启动到数据传输，全方位守护设备安全与数据隐私

安全启动与 OTP 保护

提供硬件级安全防护，安全启动确保仅运行可信固件；OTP（一次性可编程存储）用于保护设备身份。

可信启动

唯一设备身份

固件完整性

本地优先架构

无需依赖云服务，即可在本地网络中运行。固件由主机从互联网下载，再在本地完成升级；数据传输路径始终由你掌控。

双因素身份验证

添加身份验证器应用作为第二重登录验证，保护远程控制台访问安全。

跨平台免驱

可从 Windows、macOS、iOS、Linux、HarmonyOS 或 Android 控制灵控；被控设备支持 Windows、macOS、Linux 和 HarmonyOS，全程无需安装驱动。

即时发现与多设备管理

自动发现并集中管理多台灵控设备，同时对不同设备或使用环境进行访问隔离

打开 linkr.now，即可自动发现与本地主机直连或位于本地网络中的灵控设备

远程操控，如临现场

丰富的实用工具，让远程操控拥有接近本地操作的流畅体验

  1. 远程粘贴

  3. 屏幕键盘
  4. 虚拟磁盘
  5. 缩放模式
  6. 自定义快捷键

无需亲临现场，也能恢复系统

通过一个浏览器控制台，即可唤醒目标设备、进入 BIOS、挂载安装介质并完成系统恢复

局域网远程唤醒

通过灵控发送标准 Magic Packet，远程唤醒支持 Wake-on-LAN 的关机或休眠设备。

目标设备需支持并启用 WoL

ISO / IMG 虚拟介质

上传、挂载和卸载系统安装介质，用于操作系统部署、驱动加载和离线维护。

可选板载 eMMC 或 microSD 卡槽版本

EDID 与鼠标控制

配置显示兼容性，并在绝对与相对鼠标模式之间切换，满足 BIOS 和桌面环境下的操作需求。

图质 · 灵敏度 · 防止休眠

远程维护与诊断

管理设备身份、执行本地固件升级、恢复设置，并导出日志以便获得技术支持。

集中维护与故障诊断
